# 汉诺塔（Hanoi Tower）

## 一、问题描述

有三根柱子 A、B、C，A 柱上从下到上按**从大到小**的顺序叠放着 n 个圆盘。要求：

1. 每次只能移动**一个**圆盘；
2. 大盘**不能**叠在小盘上面；
3. 把所有圆盘从 A 柱全部移到 C 柱，B 柱作为辅助。

问：最少需要多少步？给出移动方案。

---

## 二、思路：递归分解

汉诺塔是讲解递归思想最经典的例子。**关键在于：把"移动 n 个盘子"这件事，拆成"移动 n-1 个盘子"这种更小但同结构的问题。**

设 `f(n)` 表示把 n 个盘子从源柱移动到目标柱的最少步数。考虑最上面的 n-1 个盘子作为一个整体：

1. 先把上面的 **n-1 个盘子**从 A → B（借助 C 作为辅助）；
2. 再把最底下的 **1 个大盘子**从 A → C；
3. 最后把 B 上的 **n-1 个盘子**从 B → C（借助 A 作为辅助）。

由此得到递推公式：

```
f(n) = 2 * f(n-1) + 1
f(1) = 1
```

解得：`f(n) = 2^n - 1`。

## 三、代码实现（Python）

```python
def hanoi(n, src, dst, aux):
    """
    把 n 个盘子从 src 柱移动到 dst 柱，aux 作为辅助柱
    """
    if n == 1:
        print(f"将盘子 1 从 {src} 移到 {dst}")
        return
    # 1. 把上面 n-1 个盘子从 src 移到 aux
    hanoi(n - 1, src, aux, dst)
    # 2. 把最底下的大盘子从 src 移到 dst
    print(f"将盘子 {n} 从 {src} 移到 {dst}")
    # 3. 把 aux 上的 n-1 个盘子移到 dst
    hanoi(n - 1, aux, dst, src)

hanoi(3, 'A', 'C', 'B')
```

输出（3 个盘子的情况，共 7 步）：
```
将盘子 1 从 A 移到 C
将盘子 2 从 A 移到 B
将盘子 1 从 C 移到 B
将盘子 3 从 A 移到 C
将盘子 1 从 B 移到 A
将盘子 2 从 B 移到 C
将盘子 1 从 A 移到 C
```

## 四、复杂度分析

| 指标 | 数值 |
|------|------|
| 时间复杂度 | O(2^n) |
| 空间复杂度（递归栈） | O(n) |
| 最少步数 | 2^n - 1 |

> 当 n = 64（传说中僧侣要解的盘子数）时，2^64 - 1 步，即使计算机每秒移动 10^9 次，也需要约 585 年。

## 五、常见易错点

- ❌ 忘记交换辅助柱和目标柱的角色（步骤 1 和步骤 3 中柱子的角色是互换的）。
- ❌ 递归终止条件写成 `n == 0` 时漏掉边界处理，建议写成 `n == 1`。
- ❌ 想用循环写出非递归版本——理论上可以，但非常绕，初学阶段**不推荐**。

## 六、拓展思考

1. **变体 1**：如果允许 4 根柱子（Frame–Stewart 算法），最少步数会显著减少。
2. **变体 2**：限制相邻两次移动不能是同一根柱子，难度大幅提升。
3. **变体 3**：用栈模拟递归过程，观察调用栈的变化。
