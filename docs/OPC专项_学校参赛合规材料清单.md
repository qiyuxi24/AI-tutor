# 人工智能OPC专项（赛道二）· 向学校提供的参赛合规证明材料清单

> 用途：向学校（教务处/双创学院/团委等申报归口部门）证明本项目**符合"人工智能OPC专项"参赛要求**。
> 依据：附件6《中国国际大学生创新大赛(2026)陕西赛区特色专项赛道方案》原文，2026-09-07 整理。
> 原则：**每条参赛要求 → 一份可核验的证据**。材料不是"写声明"，而是让审核人一眼看到证据链。

---

## 一、六条要求 → 对应证据总览

| # | 参赛要求（原文要点） | 需要证明的事实 | 提供的材料 |
|---|---------------------|----------------|------------|
| 1 | 全日制在校本专科/研究生（不含在职）；毕业5年内全日制毕业生（2021年后毕业）；允许跨校组队 | 每位成员的在读/毕业身份真实 | 每成员一份身份证明 |
| 2 | 核心主创仅1人；总团队≤15人；凸显单人主导 | 主创是谁、团队构成、单人主导体现 | 团队名册 + 主创职责说明 |
| 3 | 负责人年龄≤35周岁 | 主创出生日期 | 身份证复印件/电子件 |
| 4 | 项目以AI为核心赋能；工商注册不硬性；若注册须一人公司或主创绝对控股 | 项目AI属性 + 工商状态合规 | 项目说明页 + 营业执照（如已注册） |
| 5 | 同一项目不得跨赛道/跨标准赛道重复报名 | 未在别处重复申报 | 承诺书 |
| 6 | 知识产权清晰真实合规，严禁借用抄袭；禁止往年国赛获奖项目重复参赛 | 原创性 + 无既往国赛获奖 | 原创与合规承诺书 + 佐证 |

> 注：晋级规则（省专项获奖推国赛时按属性归入国标赛道）不需要向学校出示材料，但申报书里建议写清本项目未来可能的国标归类，便于校方理解。

## 二、材料包清单（建议按此顺序装订/打包）

### 1. 团队与主创身份证明（每人一份，成员共 N 人）
每个成员按身份提供其一，**并单独标注谁是核心主创**：

| 成员身份 | 需提供 | 出证方式 |
|---------|--------|---------|
| 在校生 | 学籍证明 / 学生证信息页 / 学信网《教育部学籍在线验证报告》 | 学信网或学校教务处 |
| 研究生（含在读博士） | 同上 + 能证明**非在职**的材料（录取类别为全日制/非定向等） | 学信网/研究生院 |
| 2021年后毕业的全日制毕业生 | 毕业证 + 学位证 + 学信网《学历证书电子注册备案表》 | 学信网 |

**关照点：**
- "不含在职教育"是硬杠：在职研究生（如定向/委培/非全日制里的在职就读）不满足，务必逐人核验录取类别。
- 跨校组队：各成员由**本人所在学校**出证明；跨校情况需在申报书"团队组成"里如实填写。

### 2. 团队名册（一页表，附在申报书后）
| 序号 | 姓名 | 角色（核心主创/成员） | 学校 | 专业 | 学号 | 学籍状态 | 出生日期 |
|---|---|---|---|---|---|---|---|
| 1 | XX | **核心主创（唯一）** | XX大学 | XX | XXXX | 全日制在校（研究生/本科） | 19XX-XX |
| 2 | XX | 成员 | … | … | … | … | … |

**关照点：**
- **"核心主创仅1人"是全案最关键的合规点。** 表格里核心主创只能出现一次；其余成员角色写"成员/协作开发"，不要出现"联合创始人""共同主创""并列负责人"等字样。
- 与 BP v2 的口径衔接：BP 里佀佳超是"创始人/AI Agent 核心开发"，其他人是分工成员——这正好符合"1 核心主创 + 成员"结构。**给学校的所有材料沿用同一口径，不得出现与 BP"5人共同创立"歧义的写法**（BP 相关章节需同步核对，见文末附注）。

### 3. 主创资格与"单人主导"说明（约半页）
内容建议：
- 主创姓名、学校、在读状态、出生日期（对应年龄≤35）。
- 单人主导的具体体现：主导产品定义与核心架构、负责 AI/Agent 主链路开发、控制产品方向与迭代节奏；成员在指定模块协作。
- 若主创同时是项目商业/运营主导，一并写明（贴合 OPC"打通创意研发→产品迭代→市场运营→客户服务闭环"的定位）。

### 4. 项目合规说明页
- 项目以 AI 为核心赋能：一句话 + 技术栈摘要（大模型、Agent、知识图谱、RAG 等），证明符合"鼓励方向（AI教育服务等）"。
- 工商注册状态（三选一写明）：
  - **未注册**：写"未工商注册"即可（规则不硬性要求）。
  - **已注册**：提供营业执照 + 证明**一人公司或主创绝对控股**（股权结构/章程/股东名册）。
- 已注册场景的**关照点**：绝对控股一般指持股比例过半或能实际控制，需股权文件支撑；若注册主体股权复杂，务必提前核实是否满足"主创绝对控股"。

### 5. 合规承诺书（主创签字）
一份承诺书里明确声明：
1. 本团队同一项目**仅在本特色专项赛道申报**，未同时在国标赛道或其他省级特色专项重复报名；
2. 项目知识产权清晰、真实、合规，无借用、抄袭；第三方素材/开源组件已按许可合规使用；
3. 本项目**未获往年国赛奖项**，不属于被禁止重复参赛的项目；
4. 团队信息真实，主创唯一，年龄符合要求。

### 6. 佐证附件（加分项，可随附）
- GitHub 仓库 / 代码提交记录 / 原创文档（证明开发原创与真实性）
- 演示视频链接、测试报告等（证明项目真实可运行）

## 三、需要特别关照的方面（最容易出问题的地方）

1. **"单人主导"与团队规模的口径**
   OPC 允许团队≤15 人，但必须"核心主创仅1人、凸显单人主导创业核心特征"。给学校的材料要**明确主创身份，弱化"多人共同创立"表述**——这与 BP 强调"5人真实团队"是相反张力，两份文档必须能自洽：BP 表述为"创始人主导 + 成员按模块分工"即合规，**严禁出现"5 位创始人/共同发起"式描述**。

2. **年龄计算基准日**
   "负责人年龄不超过35周岁"要按主办方规定的基准日计算（通常是报名截止或申报日）。提交前按身份证出生日期实算一次，留足余量（主创越年轻越不用纠结）。

3. **在校/毕业身份的时间点**
   所有身份证明以"报名/评审进行时仍有效"为准：在校生需当时仍在籍；毕业 5 年内的起算（2021年后毕业）要逐人核对是否落在这个窗口，尤其刚毕业和临近 5 年的成员。

4. **跨校组队的协调成本**
   每名成员都要自己学校出证，非主创所在学校的成员要提前联系各自教务处/学院盖章，预留时间，别卡在申报截止前。

5. **与另外两个赛事的材料不要混用**
   本项目同时涉及"AI+教育"创新应用技能大赛（团队≤5人/1主持人）等赛事，各赛事对团队结构要求不同。**给陕西特色专项 OPC 的材料要按本清单单独制作**，直接复用他赛材料会导致团队口径错位。

6. **知识产权与开源合规**
   若项目使用开源代码/第三方组件/AI 生成素材，承诺书要能兜底：明确"已按许可使用、来源可追溯"。学校若追问，要拿得出代码仓库与依赖清单。

7. **"未注册"比"将注册"更稳妥**
   规则说注册不硬性；若公司主体还没成立或股权不清，申报阶段写"未工商注册"即可，**不要写"即将注册/正在注册"**，避免引入需要证明控股的新问题。

## 四、材料准备 SOP（照着做即可）

1. **先问归口部门**：向学校确认 OPC 专项由哪个部门受理（教务处/创新创业学院/团委）、校方是否有自己的报名表和截止时间（通常早于省赛系统截止）。
2. **定团队口径**：确认核心主创 1 人（其余为成员），把名册表填好，逐人核对在读/毕业/年龄三项硬指标。
3. **各成员出证**：学信网验证报告 / 在校证明 / 毕业证学位证，跨校成员提前走流程。
4. **起草三份文字材料**：单人主导说明（半页）、项目合规说明页（含工商状态）、合规承诺书（主创签字）。
5. **校内材料与 BP 口径互检**：重点查"创始人/主创"表述、团队人数表述在两份文件里是否一致。
6. **装订提交**：按校方要求提交电子/纸质，留好提交回执。
