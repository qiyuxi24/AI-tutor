## 一、结论速览

**Q：能不能直接进国赛？**

**不能，没有任何直通通道。** 算法创新赛道是"赛区制"三级赛制，路径唯一：

```
校赛（学校自组织，10/10 前完成）
  → 省赛/区域赛（报名截止 10/15 20:00，最迟 11/1 完成）
    → 全国总决赛（11 月中下旬，国赛证书）
```

晋级规则（第八届官方原文）：
- 普通赛区：省赛**一、二等奖晋级总决赛**。省赛设奖比例为有效作品数的 ≤15%（一等）/ ≤25%（二等）/ ≤30%（三等）——即**约 40% 的省赛作品最终能拿到省级奖项，其中 40%（一+二等）进国赛**。
- 特例：若本省将大赛纳入省教育主管部门竞赛名录，则按**不超过有效作品总数 40% 推荐总决赛**（推荐制，比例更高）。

**对我们的含义：进国赛 ≠ 千军万马过独木桥，真正瓶颈是省赛拿二等以上。** 第七届创新赛道总决赛名单有 122 页（仅"AI+未来场景"一个赛题就有 8 个国一、14 个国二），国赛盘子很大——**省赛拿奖是大概率事件，省赛冲一等是主战场**。这与"AI+教育"赛道（50% 进决赛）的逻辑一致：**赛道选择正确时，进国赛的难度主要在省赛一轮**。

⚠️ **前置风险（本周必须确认）**：校赛由学校自行组织，部分高校（如武汉理工、南京邮电）用校赛选拔"代表学校参赛"的队伍。**西工大是否组织 AIC 校赛、是否有校内推荐门槛，目前查不到任何公开信息** → 走 `COMPETITION.md` Part H 的校内确认项（创新创业学院/计算机学院）。若西工大不组织，官网（www.aicomp.cn，4/28 起开放报名）按"参赛学生"身份直接注册报名省赛即可（注册身份选定后不可转，务必选对）。

## 三、评分规则（第六届官方评分公式，第八届细则待官网公布）

第六届赛题规则 PDF 给出了完整的评分公式（第八届改为 7 道赛题后细则未出，**但官方评审框架历来稳定，此公式是当前最可靠的参照**）：

**评审维度**（各 0-100 分）：
| 项 | 含义 |
|----|------|
| A | 选题、可行性与实用性 |
| B | 技术难度 |
| C | 创新度 |
| D | **完成度（现场演示或 PPT 中含"无剪辑、一镜到底"演示视频）** |
| E | 其他（材料规范性、答辩表现） |
| F | 原创性 |
| G | 应用性（**产学研合作协议、合同等支撑材料**，附加 5 分） |

**总分公式**（学科发展/新四科类，即对应现在的"AI+学科交叉"）：

```
总分 = ((0.5A + 0.2B + 0.3F) / 100) × (0.5C + 0.4D + 0.1E) + G
```

（未来场景类把后段权重改为 0.7C + 0.2D + 0.1E，更偏创新创意。）

**这个公式的杀伤力在结构**：
1. **前段是乘数系数**（最高 1.0）：选题可行性(0.5) + 技术难度(0.2) + 原创性(0.3)。任何一项低分会**成比例地压扁**后面所有得分——原创性存疑（如被看出是套壳/复用开源项目无增量）= 直接乘 0.3 倍，后面做得再好也翻不了身。
2. **后段才是得分主体**：创新度 0.5 + **完成度 0.4** + 表达 0.1。完成度明文要求**"无剪辑、一镜到底"演示视频**——评委防的就是"PPT 工程"。一个真实可跑的系统 + 流畅一镜到底演示，值 40% 权重。
3. G 附加分提示：**有真实用户/合作协议/试点合同能 +5 分**，在国一梯队 5 分就是名次差。

**对 TutorAgent 的直接推论**：
- A（选题）：大学生自学痛点 + "AI+学科交叉·自主学习"点题 → 我们强项；
- B（技术难度）：Agent loop + 知识图谱 + 混合检索，技术报告必须写出纵深（参照 `COMPETITION.md` D3）；
- F（原创性）：本届期间（2026-04 后）创作 ✅；**材料里要显式讲"自研了什么"**（图谱参照系契约、掌握度信号设计、rag_pipeline 可插拔路由），而不是"用了什么开源"；
- D（完成度）：**现在就要按"一镜到底"标准排练演示**——两阶段流式对话 → 图谱生长 → 路径生成 → 出题判分，一条镜头拍完；这也是 E3 演示稳定性清单的由来；
- G（应用性）：哪怕小规模真实试用（几个同学 + 使用记录截图）也要凑出来，是免费 5 分。

## 四、往届最好项目的实现与叙事（案例库）

> 说明：算法创新赛道官方名单只公布团队与等次、不公布项目名，完整作品细节不公开；以下案例来自获奖高校新闻 + 可比赛道（产业命题"AI智能体开发应用赛"、大模型任务挑战赛）的公开报道，**叙事模式与评审口味与算法创新赛道同源**（同一组委会、同一"人工智能+"框架、同样的四能力考察：算法创新/工程实践/创新思维/团队协作）。

### 案例 1：郑州商学院 · 产业命题 AI 智能体开发应用赛 · 国一（第七届）
- **成绩叙事**：全国总成绩 96.0，与深圳大学并列第 10（本科组 149 支决赛队，参赛校含同济/华科/西交/深大）。
- **考察内容（官方口径）**：AI 智能体架构设计、**知识库搭建**、智能体搭建及应用测试**全流程实操**，技术场景适配 + 商业价值落地综合考量。
- **给我们的信号**：经管类二本院校靠"知识库 + 智能体"工程完成度打赢 985 —— **这个赛系的评审不看出身、看作品完成度与实操**；TutorAgent 的知识图谱+KB 体系正对口味。

### 案例 2：北京信息科技大学 · 神思杯能源问数模型 · 国一（第七届）
- **实现**：Text-to-SQL 让非技术人员自然语言查询复杂能源运行数据；获奖叙事强调"对 Text-to-SQL 技术的深刻理解 + 对工业数据业务逻辑的精准把握"。
- **叙事模式**：**单点技术纵深 + 垂直领域业务理解**，不是大而全的平台故事。
- 对照：我们的对应物 = "知识图谱参照系 + 掌握度信号设计"，要能讲到这个深度。

### 案例 3：江南大学 · 智慧社区方向 · 国一（第七届，157 校 541 队）
- 叙事锚点：城市化背景下社区治理人力痛点（出入管控/安防巡逻/车辆管理）→ AI 方案。**典型的"国家叙事 → 场景痛点 → 技术方案"三段式**。

### 案例 4：湖北工业大学 · 大模型任务挑战赛 · 全国第一（第七届，102 支决赛队）
- **实现**：大模型解析自然语言 → 转机器人执行指令，模拟月面任务；综合考查大模型部署 + CV + 路径规划 + 系统集成。
- **叙事模式**：前沿主题（航天）+ 多能力集成 + 排名数字化（"102 支队伍中全国第一"）。

### 案例 5：商丘师范学院 · "好运来"团队 · AI 智能体开发应用赛国一
- 经管学院本科生（非科班），靠"扎实的专业基础 + 创新的 AI 应用解决方案 + **出色的现场答辩表现**"拿河南省第一。
- **信号**：现场答辩是决胜变量；非计算机专业不是劣势，**场景理解反而是加分项**。

### 案例 6：山东药品食品职业学院 · 智能体赛项省三（叙事反面教材级细节）
- 新闻披露的实现细节："提前两周完成**实体关系抽取**、比赛当天手动标注 200 条高质量数据保障链路效果；搭建'对话+审核+预警'三合一可视化界面，**一键部署、开箱即用**"。
- **信号**：连省三队伍都在讲"数据质量保障 + 开箱即用"——**评委对"真实数据投入"和"部署易用性"极其敏感**。我们的 211 自动化测试、Docker 一键部署、whoosh 兜底降级都是同类弹药，要写进材料。

### 规模参照（第七届算法创新赛道总决赛获奖盘子）
- 算法模型创新·本专生组：国一 16 队、国二 29 队、国三 ~14 队（另设研究生组）；
- AI+未来场景：国一 8 队、国二 14 队、国三 15 队；
- 全名单 122 页，六大赛题类别合计**数百个国奖**。结论：**进了总决赛，拿国奖（含三等）概率很高（≤15+25+30=70%）**；真正的分水岭在省赛一等 vs 二等。

## 五、获奖叙事的共性公式（对仗到 TutorAgent）

从上述案例提炼，国一项目的叙事骨架高度一致：

```
① 国家叙事/政策锚点（AI+行动、人工智能赋能千行百业）
   → ② 一个具体场景的真痛点（越具体越好，反"大而全"）
      → ③ 技术纵深的单点突破（"对 X 技术的深刻理解 + 对 Y 业务逻辑的精准把握"）
         → ④ 一镜到底的真实系统演示（完成度 0.4 权重）
            → ⑤ 量化证据（排名/分数/指标/用户数）
               → ⑥ 落地与推广（协议/试点/开箱即用）
```

TutorAgent 的对应填空（直接可用于技术报告与答辩开场）：
- ① 国家"人工智能+"行动 + 教育数字化；
- ② 大学生自学三痛点（碎片化/无反馈/笔记负担）——已有；
- ③ 单点突破 = **"知识图谱驱动的自适应导学"**：图谱参照系契约（三问 L1/L2/L3）、掌握度以出题判分为唯一硬信号、混合检索（向量+BM25+RRF）；**不要讲成"我们做了很多功能"**；
- ④ 一镜到底演示（E3 清单）；⑤ CMRC 检索指标 + 出题质量 + 延迟（D3 量化清单）；⑥ 真实试用记录 + Docker 一键部署。

## 七、赛道 × 赛题对比：算法创新赛道 vs「AI+学科交叉」（第七届国奖实测 + 第八届规则定稿）

> 创建：2026-09-20。回答：**"算法创新赛"和"学科交叉"这两个说法是什么关系？去年国奖盘子差多少？各自特点？我们选哪个？**
> 数据来源（全部原文，非二手转述）：① 第七届总决赛（算法创新赛道）拟获奖名单 PDF 122 页（〔2025〕143 号，2025-12-12 公示）② 第八届"算法创新赛道"竞赛通知（〔2026〕11 号，2026-04-29）③ **第八届《算法创新赛赛题规则汇总》（260506，含 7 道赛题逐条评分表）** ④ 第七届算法主题赛道"AI+力学"国赛名单 ⑤ 第八届算法主题赛（AI+医学）通知。抓取/解析方法见 7.8。

### 7.1 先厘清口径：不是两条赛道，是三层结构

| 层级 | 名称 | 2025（第七届） | 2026（第八届） | 赛制 |
|---|---|---|---|---|
| 赛道 | **算法创新赛**（承办赛道，赛区制） | 6 个赛题方向 | **7 道开放式赛题** | 校赛 → 省赛/区域赛 → 全国总决赛（省一/二等晋级） |
| 赛题 | 其中的一道**赛题** | 无此赛题；"交叉学科"是 AI+应用创新 / AI+创新创业 下的 **8 个学科子类之一** | **赛题5：AI+学科交叉**（独立设奖） | 同上（同一赛道内） |
| 另一条线 | 算法**主题**赛道（不在算法创新赛道内） | AI+力学 / AI+医学 / 智慧气象 … 每个学科主题一场 | 15 个主题（智能体互联、AI+医学、AI+力学、AI+能源…） | **初赛 → 复赛（等同省级）→ 总决赛，不分赛区**，通知单独发布 |

**结论：所谓"算法创新赛 vs 学科交叉赛道"其实是"整条赛道 vs 其中一道赛题"**；如果指"专门做学科+AI 的独立赛事"，那是**算法主题赛道**（7.4）。三者的报名入口、赛区规则、材料要求都不同，不能混为一谈。

- README/材料是**功能清单式**（15 行 ✅ 表格），不是**用户故事式**。评委记不住 15 个功能，只记得住一句话——而我们现在的一句话"知识图谱驱动的自适应导学 Agent"听着像毕设题目，不是产品。
- **最值钱的差异化资产全部埋没**：从零自研 agent loop（非 LangChain 脚手架）、掌握度四档+判分主信号设计、运行证据回放（agent_runs 全量落盘）、上下文预算框架、版权双模式——这些评委一个都看不见，因为没写进任何对外材料。评委默认感知："FastAPI+Vue+RAG = 又一个大作业"。
- **"和豆包/Kimi 有什么区别"没有演示级答案**——讽刺的是 `backend/scripts/eval_graph_injection.py`（adaptive vs free_talk 对照）**已经写好了，只是从没跑出数字放进材料**。

**④ 修正后的距离结论：** 之前说"差距全在证据层，没有一项需要技术攻关"——**收回一半**。证据层（实验/视频/用户）仍是运营型工作，但 UI 聚焦和叙事重构是**产品判断力的活**，做砸了 D 完成度和 E 表达一起塌。补齐清单（并入 8.3 排序）：

| # | 动作 | 补哪项 | 优先级 |
|---|------|-------|-------|
| 9 | `seed_demo` 演示账号：预填"数据结构"图谱 20 节点+画像+历史对话+题库，评委登录即满血 | D 演示体验 | **P0** |
| 10 | 导航降焦：演示动线只暴露 对话→图谱→仪表盘 三页，Collector/Settings 收二级 | D 产品聚焦 | P1 |
| 11 | 视觉统一：设计 token（主色/字体阶/间距/空态），克制改造不推翻 | D/E | P1 |
| 12 | 叙事重写：材料首页改"小李期中复习 30 分钟"用户旅程 + 一句话定位（对豆包的差异化） | E/C | **P0** |
| 13 | 跑 `eval_graph_injection.py` 出表（脚本现成） | C | **P0**（并入 #2） |

### 8.6 现在能做什么（可执行清单，9/19 基准）

> 报名截止 10/15，当前→截止 = 4 周倒计时。

**① 用户测试 —— 今天就能启动，G 那 5 分是白送的，但要“证据化”**
- 远程 demo 已在 `http://100.90.96.111:8080` 跑着，找 2-3 个同学发账号就用，零部署成本。
- **别做成“体验反馈”，要做成“实验”**：找 1-2 个真在修“数据结构”的同学，用系统 2 周，出题系统现成的 `grade_answer` 能拉出**前后测分数对比 + 掌握度变化曲线**——这在评委眼里是“教学效果验证”（C+G 双吃），比“用户说好用”高一个量级。
- 坑：用户测试会烧 LLM key（成本要预算）；使用记录截图/频率统计要从第一周就开始留，事后补不了。

**② 找老师 —— 本周就去敲办公室，这是 10 月内唯一能把 G 从 0 变 5 的路径**
- 赛制允许 ≤2 指导教师，且 G 附加分明文认“产学研协议/学校推荐”。三层收益：
  - 挂指导老师（尤其 AI/教育方向）→ 答辩背书 + 院系推荐资格；
  - 问他有没有试点通道——**哪怕借一个班做一次真实课堂使用 = G 满分叙事**；
  - 找教“数据结构”的老师要一段教学视角的评价（引用进技术报告）。
- 提醒：G 是“加分项”，挂名老师不等于加满，**试点证据才是硬通货**。

**③ Paper 落地 —— 诚实说：10 月内别碰，但可以“paper 思维”**
- 我们的 novelty（agent loop 是成熟范式、RRF 混合检索是标准技术）撑不了一作顶会，10 月截稿的会也没赶上有意义的目标。硬投 = 浪费最贵的 4 周。
- 但 **paper 的“实验节格式”正是 C 创新度（0.5 权重）缺的东西**：方法图 + 消融表（混合检索四路对比）+ 对照实验（有图谱 vs 无图谱）。把 `eval_rag.py` / `eval_graph_injection.py` 跑出表，按 paper 实验节的样式排进技术报告——这是“用 paper 的壳，装比赛的分”。

**④ 时间线（9/19 → 10/15，共 4 周）**

| 周 | 动作 |
|---|---|
| 第 1 周 | **恢复 embedding key**（一票否决项，已延期 6 天）；跑两个 eval 脚本出表；去找老师 |
| 第 2 周 | `seed_demo` 演示数据；找同学发账号开始用户测试 |
| 第 3 周 | 叙事重写 + 导航降焦 + 一镜到底视频（3-5 分钟无剪辑） |
| 第 4 周 | 答辩 Q&A 题库演练 + 材料终稿 + 报名提交（10/15 截止） |

### 8.7 按现在完成度，能拿到什么？（条件分支，9/19 基准）

按公式自评 **≈50 分 → 省赛二等~三等**。但有两个前提：

- **前提一（最大风险）**：embedding key 还欠费。演示当天断链 = D 一票否决，实际可能掉到省三以下。
- **前提二（比扣分更狠）**：评委拿到的是**空账号**（零演示数据）。空图谱+空对话的第一印象是“半成品”，实际观感可能比 50 还低。

| 情形 | 预期结果 |
|---|---|
| **什么都不做**，key 还断着 | 省三或更差，演示有翻车风险 |
| **什么都不做**，key 正常 | 省二~省三稳，省一无望 |
| **只做便宜三样**（eval 出表 + seed_demo + 3 个同学用两周） | 省一可争，这仨大概值 10-15 分 |
| **4 周把 P0 全做完**（+ 视频叙事 + 老师试点） | ≈82 分 = **国一边缘**，国二可期 |

**一句话结论：现在的完成度 = 省二；做完全部 P0 = 摸到国一的边。差的 30 分里没有一分需要写新功能，但每一分都需要这 4 周的天数。最大的敌人不是评委、不是人情世故，是 10/15 这个日期。**
