## 0. 一句话结论（先定三个口径）

1. **母带一次录、两版各剪**：录 10 分钟用不到的素材（每幕单独录、多录 1–2 条），A 版按 2/6/2 拼，B 版从同一批素材重剪成 3–5 分钟。不要为 B 版单独重录。
2. **AIC 版的重心不是"功能多"，是"效果有数"**：官方评分表里 `项目实施 20 + 应用效果 20`，而「应用效果」明文要**教学试点数据/用户反馈**；「需求分析」里"未明确具体学科领域"直接 0–4 分 → AIC 版**开场 15 秒内必须点出"数据结构"这门课**，且必须留 30–45 秒给前后测数据。
3. **⚠️ 当前最大缺口 = 应用效果证据**：`docs/架构/可演示事实清单.md` §5 明确禁止"有真实用户"这类说法，目前**没有试点数据**。这条不补，AIC 版 20 分只能拿 0–6 档（功能完整性再高也拉不回）。→ 见 §6「P0 补数据」。

> 🔴 **10/15 不是缓冲日**：AI+教育"报名与材料提交截止 2026-10-15"，且**截止后不再受理任何修改、补充**（材料缺失/格式不符按无效申报处理）；AIC 省赛/区域赛报名缴费截止也是 **10/15 20:00**。两个截止撞车 → **10/14 必须完成全部导出**，10/15 只留"上传 + 复核"两件事。

**工作流铁律**：① **先录画面、后配旁白**（画面镜头是死的，旁白可以慢慢对齐）；② **分段录、分段存**（`raw/A1.mp4 … B5.mp4`），不要一镜到底赌运气；③ 每段录完**立刻看一遍**再录下一条；④ 平行推进：等出题那 40 s 时不要停，继续录下一幕素材。

### 7.1 录制参数（OBS，照抄）

| 项 | 值 | 说明 |
|---|---|---|
| 输出分辨率 | 1920×1080（16:9） | 与素材截图一致；**AIC 明文要求分辨率不低于 1080p** |
| 帧率 | 录制 30 fps → **导出 25 fps** | 纯录屏无快速运动，25 与 30 肉眼无差；国内教学资源评审常见口径是 25 帧 |
| 编码/码率 | H.264（NVENC 可选）/ CBR 12000 Kbps（或 CQP 18–20），关键帧间隔 2 s | 1080p 录屏 10–12 Mbps 是清晰与体积的平衡点 |
| 色彩 | NV12 / 709 | 录屏文字边缘不发灰 |
| 音频 | 48 kHz，旁白轨与系统音分开 | 后期能单独调音量 |
| 鼠标 | 开「**高亮鼠标**」 | 省掉后期画红圈（参照库 §四 #5） |
| 浏览器 | 缩放 100%、关无关标签、固定深浅主题 | 演示卡自检项 |
| 录制方式 | **窗口捕获**（只录浏览器窗口，避免任务栏/桌面泄名校名） | 比全屏捕获更能防脱敏事故 |
| 片头长度 | 3–5 s 纯文字卡 | 国内规范口径"片头 5 秒"；**AIC 版绝不能含校徽校名** |

### 7.2 剪辑流程（剪映专业版，六步）

1. **清垃圾**：剪掉每次操作之间的犹豫、误点、加载等待（这是最大的一笔时间节省）。
2. **变速**：出题 40 s、索引等待 → 4–8× 变速，右下角加"×6"角标（参照 [Recorded 变速做法](https://recorded.app/zh-TW/blog/speed-ramping-screen-recordings/)）。
3. **聚焦**：看不清的细节用**蒙版 + 关键帧缩放**放大到 1.5–2×，3–4 s 后回位；不要整屏长时间放大。
4. **字幕**：智能字幕打底 → 人工改错 → 关键数字/术语加色加粗；字号在 1080p 下 ≥ 40 px。
5. **旁白**：按幕分段录（错一句重录一句，别整片重来）；语速 ~220–240 字/分钟；音量归一化到 **-16 LUFS** 左右；配乐只放 -25 dB 以下且**必须无版权**（剪映自带音乐库内选）。
6. **导出**：MP4 / **H.264(AVC)** / 1920×1080 / **25 fps** / AAC 192 kbps。A 版码率 **6 Mbps**（10 min ≈ 450 MB，500 MB ÷ 10 min ≈ 6.7 Mbps 理论上限）；B 版 **8 Mbps**（4 min ≈ 240 MB）。**导出后看文件属性确认体积**；超体积就降到 5 Mbps，**不要降分辨率**（AIC 明文要求 ≥1080p）。

## 8. 交付自检清单（导出后逐项打勾）

- [ ] 时长：A ≤10:00（推荐 9:30）／B 在 3:00–5:00 之间（推荐 3:40）
- [ ] 体积：A ≤500 MB／B ≤300 MB（读文件属性，不是估算）
- [ ] 格式：MP4（**H.264/AVC** + AAC），Windows 自带播放器 + 浏览器都能播
- [ ] 分辨率 **≥1920×1080（16:9）**、帧率 25 fps（AIC 明文"分辨率不低于 1080p"）
- [ ] 片头 3–5 s；片头/字幕/旁白均无校名（AIC 版）
- [ ] 字幕：全程有字幕、无错别字、无被画面遮住的关键字
- [ ] 音量：旁白清晰、无明显忽大忽小、无爆音；配乐不盖人声
- [ ] 无无关水印/第三方品牌/付费账号信息
- [ ] **AIC 版：无校名、无校徽、无指导教师**（§5.2 全勾）
- [ ] 旁白里**没有** `可演示事实清单` §5 的禁止说法
- [ ] 命名：AIC 版按 `参赛编号-赛题名-作品名-材料名`
- [ ] 备用：A 版另存一份"弱网兜底版"（关键幕用截图替代录屏）
- [ ] ⏰ **AI+教育"截止后不再受理任何修改、补充"** → 上传完成后截图留存回执

## 9. 风险与兜底

| 风险 | 影响 | 兜底 |
|---|---|---|
| 应用效果数据拿不到（P0-2） | AIC 版 20 分塌 | 先做**小样本**（5–10 人、3 天）也远好过没有；实在没有就在视频里如实说"小规模试用"，把分压在项目实施 |
| 出题 40 s 超时/题卡不来 | 核心幕录不成 | 提前把题卡**预先跑出来**存好，用"回看历史题 + 判分"的方式演（演示卡幕4兜底） |
| SSE 断流/后端起不来 | 整幕重录 | 独立窗口前台跑 `start.ps1 -Local`；出问题按演示卡切下一幕 |
| 导出超体积 | 提交失败 | 先按 §7.2 码率导出，超了就降到 5 Mbps（1080p 录屏内容 5 Mbps 仍清晰） |
| 剪辑时间不够 | 两版都粗糙 | **保 B 版**（3–5 min 硬规则+配分更高），A 版从 B 版素材扩写 |
| 校名遗漏 | AIC 一票否决 | §5.2 清单执行两遍：剪辑前一遍、导出后逐帧快扫一遍 |
