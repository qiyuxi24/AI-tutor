## 附 B：评审追问速答卡

| 追问 | 答法（技术口径） |
|---|---|
| Agent 为什么不用现成框架？ | 自研轻量循环：依赖最小、行为全透明、可单测；OpenAI 兼容直连便于适配国产模型差异 |
| 检索为何混合不用纯向量？ | mock 评测 BM25 R@1=0.964 优于弱向量 0.470；真实 embedding 复跑后更新融合结论，诚实标注不夸大 |
| 掌握度怎么算？ | 0–1 由对话与答题信号驱动、持续修正、支持人工调整；用于路径推荐而非绝对成绩 |
| 数据安全？ | 按用户隔离 + 可私有化部署 + 采集版权双模式（商用自动过滤受限内容） |
| 会不会被大厂一键复制？ | 图谱建模 + 引导提示链 + 混合检索 + 反馈闭环是工程组合；核心是可复现的学习闭环而非单点模型 |
