## 二、重点补强：商业模式（评委必问，目前撑不住）

### 问题 3：商业模式只有三段式路径，没有画布、没有定价、没有单位经济

**位置**：P5 1.3 节（"MVP 验证 → 高校 SaaS → 多学段平台生态"）

**问题说清楚**：现在的写法只说了"分三步走"，但**一页钱的事都没讲**：客户细分、收入来源、成本结构、定价、单校能收多少钱、获客要花多少钱、多久回本——全部空白。国创赛创意组评审有一项就是"商业性"，评委几乎一定会问：

- "一所学校买你们的产品多少钱？"
- "谁来付钱？教务处还是学生？"
- "从接触到签约要多久，一个学校你能赚多少？"

现在这份 BP 一个都答不上来。

**怎么改（分三步）**：

1. **补一页商业画布（Business Model Canvas，标准九格）**，这是成熟通用的框架，直接套用：

   | 画布模块 | AI-tutor 的填法（供参考） |
   |---|---|
   | 客户细分 | 短期：高校学生（C 端）；中期：教务处/院系（B 端）；长期：K12/职教/企业培训 |
   | 价值主张 | 有地图（知识图谱）、有路径、有记忆（学情画像）、有反馈（掌握度+出题），不是"给答案"而是"教会" |
   | 渠道 | 校内试点 + 学长学姐口碑 + 比赛背书撬动 B 端 |
   | 客户关系 | C 端免费增值 + B 端按校订阅 + 教师培训服务 |
   | 收入来源 | B 端按校/学年 SaaS 订阅 + 教师增值工具 + 单学科深度包；长期 API 开放与内容分成 |
   | 核心资源 | 知识图谱构建能力、学情画像引擎、211+ 测试的工程化代码库 |
   | 关键业务 | 图谱构建、对话导学、出题评测、试点运营 |
   | 重要伙伴 | 高校教务/在线课程平台、学科教师、LLM 供应商 |
   | 成本结构 | LLM API 调用费、服务器、试点期人力（现阶段近乎为零，可如实说） |

2. **给出假设性定价**（bp_v2 第 5 章里这几格都写着"待补"，改文档时把它补上）。参考同类产品通行区间，写明是假设即可：
   - 高校 B 端 SaaS：**3–8 万元/校/年**（对标智慧树、学习通按校订阅区间）
   - C 端增值：**单学科包月 15–30 元**（对标学习通会员等 C 端区间）
   - 教师增值工具：**500–2000 元/人/年**

3. **补一组单位经济测算**（哪怕全是假设，也要有数字和逻辑）：
   - 单校获客成本（CAC）：试点转化为主的假设，如 0.5–1 万元/校（差旅+演示+对接人力）
   - 单校年收入（客单价）× 预计续约率（如 70%）→ 得出 LTV
   - 回本周期：如"单校订阅 1 年即可覆盖获客成本，LTV/CAC > 5"
   - 关键一句话逻辑：**"C 端免费跑出留存数据 → 数据+比赛背书降低 B 端获客成本 → 按校订阅摊薄边际成本"**

素材直接从 `bp_v2/第5章_商业模式.md` 搬：5.1 客户漏斗表、5.2 分阶段营收表都能用，**缺的就是把"待补"的定价补成具体假设数字 + 新增一页画布 + 一段单位经济测算**。

## 三、重点补强：真实调研证据（全文只有未来计划，没有已发生的事实）

### 问题 4：通篇没有一条真实用户证据

**位置**：P5 1.3 节、P8 2.4 节

**问题说清楚**：文中写"2026—2027 年完成至少 3 所高校内测并争取 1000+ 名学生参与"——这是**未来要做的事，不是已经发生的证据**。痛点部分（知识碎片化、学完没反馈、笔记脱节）也都是我们的判断，没有一条来自真实用户。国创赛评审非常看重"调研深入、是真需求"，如果答辩时评委问"你怎么知道学生有这三个痛点？"，现在的 BP 答不上来。

**怎么改**：**先做调研，再把数字写进 BP**。哪怕样本很小，真实的小数据也远胜没有：

1. **问卷（本周就能做）**：面向本校学生发一份 10 题以内的问卷，目标 ≥50 份，问三个痛点是否命中、现在用什么工具、愿不愿意为解决方案付费。把回收份数和关键比例写进 BP，如：
   > "已完成 50 份问卷调研，76% 受访学生表示'学完不知道自己掌握到什么程度'是主要困扰。"

2. **深度访谈（5 人即可）**：找 5 名不同年级/专业的同学做 20 分钟访谈，各整理 2–3 条原话。BP 里引用 1–2 条典型原话（注明"受访者，大三，计算机专业"这类脱敏信息），比任何分析都有说服力。

3. **试用反馈（如果已有内测用户）**：哪怕只有几个同学用过 MVP，也把"X 名同学试用两周，反馈 XX"写进去。

4. **写进 BP 的位置**：在痛点章节（1.1/2.x）末尾加一小节"需求调研验证"，在 1.3 节把"未来内测计划"和"已完成的调研"分开写，别混在一起。
