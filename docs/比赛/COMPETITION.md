# Part B "AI+教育"OPC 赛道专项（材料最全，是其它两赛素材库）

## B1 赛道选择与理由
1. 身份匹配：面向全日制在校学生，学生团队独立申报，无需盖章
2. 主题吻合：赛道名含 **AI Agent**——TutorAgent 是完整 Agent（LLM+function calling+图谱自适应）
3. 创新创业属性：已有可运行产品级实现，闭环清晰
4. 差异化：OPC 赛道为 2026 新增细分，无历史强队；竞争者多为泛 AI+教学，真正把 agent 工程做扎实的少
- 备选：若教师愿挂帅，可走高教组"AI+教学"，但需院系盖章，协调成本高——维持学生组方案。

## B4 作品定位（已定稿）
> **TutorAgent：知识图谱驱动的自适应导学 Agent**，面向大学生自学，解决知识碎片化、无反馈、记笔记痛苦三大问题。
> 核心主张：不止是聊天，而是有记忆（画像）、有地图（图谱）、有路径（规划）、有笔记（自动生成）的 AI 学习伙伴。
> 与通用 AI（ChatGPT/Kimi/豆包）区别：知识结构可视化、学习连续性（画像）、路径规划、对话即笔记。
> 当前阶段：MVP，功能闭环可用，10 月持续完善。

- **申报书/承诺书**：官网（aiedu.caet.org.cn）注册填报 → 系统生成 PDF → 负责人签字扫描上传；学生团队免盖章；10/1 前摸熟系统字段，别压线。

- **演示视频 MP4 ≤10min ≤500MB**：概述 ≤2min / 核心演示 ≤6min / 总结 ≤2min。录制注意：弱网/断 key 备兜底录屏；字幕与音量统一；内容不得出现无关品牌水印。
