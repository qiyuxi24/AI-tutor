# AI-tutor 商业计划书 · v2 撰写任务分解

> **配套文档**：`docs/商业计划书_框架_v1.md`（框架确认稿）
> **本文档**：9 章拆分为可独立派发的子 agent 任务，含调研库、写作任务书、整合审查策略
> **更新日期**：2026-09-05
> **方法论**：借鉴 deep-research skill 的"先列大纲 → 分批深度调研 → 整合"哲学

---

## 〇、整体执行流（3 阶段）

```
阶段 1 调研库（并行启动 2-3 个调研子 agent）
  ├── 调研 A：AI 教育市场 + 竞品 + 政策 + 客户分层
  ├── 调研 B：教育学/认知科学论文（"AI 阻碍学习"理论支撑）
  └── 调研 C（可选）：高校 SaaS 定价 + 商业模式标杆
        ↓
阶段 2 写作（启动 6-9 个章节写作子 agent，按依赖关系分批）
  ├── 批次 1（依赖最少）：第 4 章 技术壁垒、第 8 章 竞争分析、第 9 章 风险
  ├── 批次 2（依赖批次 1）：第 3 章 产品、第 5 章 商业模式、第 7 章 市场
  └── 批次 3（依赖最多）：第 1 章 执行摘要、第 2 章 行业背景、第 6 章 团队
        ↓
阶段 3 整合 + 审查（启动 2 个子 agent）
  ├── 整合 A：把 9 章串成 v2 完整 BP，统一术语 / 数据 / 数字锚点
  └── 审查 B：一致性 / 智网天穹写作手法 / 风险反向营销 / 表格密度 4 维审查
```

## 一、阶段 1：调研库（3 个并行调研子 agent）

### 子 agent A · AI 教育市场 + 竞品 + 政策调研

**任务**：调研 AI 教育 Agent 赛道的市场规模、竞争格局、政策环境、客户分层、定价区间

**输入材料**：
- `docs/AI-Tutor_项目概述.md`（项目定位 + 竞品分类）
- `docs/商业计划书_框架_v1.md`（v1 框架 v1 第 2/7/8 章子结构）

**必查内容**：
1. **市场规模数据**
   - 教育部最新高校学生数（2024-2026）
   - 艾瑞 / 沙利文 / 头豹 / 36氪 AI 教育赛道报告（市场规模 + CAGR）
   - 在线学习付费意愿数据
2. **竞品深度调研**（3 类，每类 2-3 个代表）
   - 通用 AI 对话工具：ChatGPT（最新 Edu 版）/ Kimi 学术 / 豆包学习助手 / 智谱清言
   - 知识管理工具：Notion AI / Obsidian + AI / 飞书智能伙伴
   - 在线学习平台：中国大学 MOOC / 学堂在线 / 学习通 / 智慧树
3. **AI 教育政策**（教育部 / 网信办 / 国标）
   - 《新一代人工智能发展规划》教育相关条款
   - 教育部"AI+教育"行动相关文件
   - 大模型教育应用合规要求
4. **高校 SaaS 定价**（商业模式标杆）
   - 学习通 / 智慧树 / 中国大学 MOOC 平台报价
   - 海外类似产品定价（Quizlet Plus / Photomath / Socratic by Google）

**输出格式**（结构化）：
```markdown
# 调研 A：AI 教育市场 + 竞品 + 政策

## 1. 市场规模
- 高校学生数：[数据] + [来源链接]
- AI 教育市场规模：[数据] + CAGR + [来源链接]
- 在线学习付费意愿：[数据] + [来源链接]

## 2. 竞品深度分析（表格）
| 竞品 | 类型 | 核心功能 | 定价 | 优势 | 劣势 | 来源 |

## 3. 政策环境
- 政策清单 + 条款摘要 + 对本项目影响

## 4. 商业模式标杆
- 标杆产品定价 + 商业模式 + 关键参考点

## 5. 核心结论（5-10 条）
- 给后续章节写作的可直接引用结论
```

### 子 agent B · 教育学/认知科学论文调研

**任务**：为"AI 直接给答案阻碍学习"这一根本痛点找学术理论支撑，调研 5-10 篇经典论文

**必查方向**：
1. **检索式练习 / Testing Effect**
   - Roediger & Karpicke (2008) "Test-enhanced learning" — 经典 Science 论文
   - Karpicke 后续工作
2. **主动学习 vs 被动学习**
   - Freeman et al. (2014) "Active learning increases student performance" — PNAS
   - Bonwell & Eison "Active Learning: Creating Excitement in the Classroom"
3. **苏格拉底式方法 / Socratic Method**
   - Paul & Elder "The Thinker's Guide to the Art of Socratic Questioning"
   - LLM 实现 Socratic tutoring 的最新论文（2024-2026）
4. **认知负荷理论 / Cognitive Load Theory**
   - Sweller et al. (1998, 2019) — Cognitive Architecture and Instructional Design
5. **AI 过度依赖 / Over-reliance on AI**
   - 2024-2026 最新论文：大学生过度依赖 ChatGPT 对学习的影响
   - "Cognitive offloading" 相关研究

**输出格式**（结构化）：
```markdown
# 调研 B：教育学论文调研

## 1. 检索式练习（Testing Effect）
- 核心论文：Roediger & Karpicke (2008)
- 关键数据：被动阅读 24h 保留率 vs 主动检索 24h 保留率
- 一句话结论：...

## 2. 主动学习
- 核心论文：Freeman et al. (2014)
- 关键数据：...
- 一句话结论：...

## 3. 苏格拉底式方法
- ...

## 4. AI 过度依赖
- 2024-2026 关键论文清单
- 关键发现：...
- 一句话结论：...

## 5. 引用清单（10-15 篇）
- 论文名 / 作者 / 年份 / 期刊 / 链接 / 核心贡献（一句话）
```

**任务**：

---

### 审查子 agent RA · 一致性审查

**任务**：按智网天穹写作手法做 4 维审查

1. **数字锚点贯穿**：执行摘要 / 产品 / 技术 / 竞争 / 风险各章是否反复出现同一组核心指标
2. **痛点↔模块↔技术↔优势四级映射**：3 个痛点 → 3 个产品能力 → 3 项核心技术 → 3 条竞争优势一一对应
3. **表格密度**：产品形态、性能指标、竞争格局、风险全景是否用表格
4. **风险章节反向营销**：每条风险的应对策略是否回收前面章节的既有优势

**输出**：`docs/bp_v2/审查报告_v2.md`（含问题清单 + 修复建议）
