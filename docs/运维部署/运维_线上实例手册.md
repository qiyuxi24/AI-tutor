## 二、拓扑与访问模型

```
浏览器 ──HTTP:80──▶ 宿主 nginx（网关 + 限流）
                      ├─ 无通行 Cookie → 302 /gate → Basic 认证 → 下发 Cookie
                      └─ 有通行 Cookie → 反代 127.0.0.1:8080
                                                      │
                                       容器 ai-tutor（绑定 127.0.0.1:8080）
                                        ├─ 容器内 Nginx :80 → 前端静态 + /api 反代
                                        └─ 容器内 Uvicorn :8000（--workers 1）
```

### 2.1 为什么不是"全站 Basic Auth"（关键设计取舍）

**不能**对全站开 `auth_basic`，否则站点会整体不可用：

> 前端 `frontend/src/api/index.js` 对所有 `/api/v1/*` 请求**显式**设置
> `Authorization: Bearer <JWT>`。HTTP 只允许一个 `Authorization` 头 —— 这个 Bearer
> 会**顶掉**浏览器自动附带的 Basic 凭据 → nginx 的 `auth_basic` 判 401 → 全部接口挂掉。
> （静态资源没有该头，会被浏览器补上 Basic，所以"能打开首页但接口全 401"是典型症状。）

因此改用 **Cookie 通行证**：`/gate` 页做 Basic 认证，通过后用 JS 下发
`tutor_gate=<32位随机值>`；业务 location 用 `map` 校验该 Cookie，与 Bearer 头互不冲突。

### 2.2 验证记录（2026-10-06，从公网实测）

| 步骤 | 请求 | 期望 | 实测 |
|---|---|---|---|
| 1 | `GET /`（无通行证） | 打回网关 | 401 ✅ |
| 2 | `GET /gate`（无凭据） | 401 | 401 ✅ |
| 3 | `GET /gate`（有凭据） | 200 + 通行脚本 | 200，含脚本 ✅ |
| 4 | `GET /api/v1/auth/public-key`（带 Cookie） | 200 | 200 ✅ |
| 5 | `POST /api/v1/auth/login`（带 Cookie） | 200 + token | 200 ✅ |
| 6 | `POST /api/v1/chat`（Cookie + Bearer） | 200 + 真实回复 | 200，LLM 正常应答 ✅ |
| 7 | `GET /api/v1/knowledge/events`（SSE） | 200 `text/event-stream` | 200 ✅ |

## 三、安全加固清单

### 3.1 SSH：仅密钥登录

`/etc/ssh/sshd_config.d/99-hardening.conf`：

```ini
PasswordAuthentication no
KbdInteractiveAuthentication no
PubkeyAuthentication yes
PermitRootLogin prohibit-password
X11Forwarding no
AllowAgentForwarding no
AllowTcpForwarding no
MaxAuthTries 3
MaxSessions 6
LoginGraceTime 20
DebianBanner no
```

生效核对：`sshd -T | grep -E '^(passwordauthentication|permitrootlogin|maxauthtries)'`
→ 期望 `no` / `without-password` / `3`。

> 顺序要点：Ubuntu 的 `sshd_config` 第 12 行就 `Include /etc/ssh/sshd_config.d/*.conf`，
> 且 sshd 采信**首个**出现的取值 —— 所以 `99-hardening.conf` 里的值优先生效。

### 3.2 fail2ban：SSH 爆破自动封禁

`/etc/fail2ban/jail.local`：

```ini
[DEFAULT]
ignoreip = 127.0.0.1/8 ::1 1.80.217.47
bantime  = 1h
findtime = 10m
maxretry = 5

[sshd]
enabled  = true
port     = ssh
backend  = systemd
maxretry = 4
bantime  = 2h
```

> `ignoreip` 里的公网 IP 是**当时运维用的出口 IP**，换网络环境后需同步，否则可能被自己误封。

### 3.3 端口暴露面

对 29 个常见端口做公网 TCP 探测，结果：

```
对外开放 : [22, 80]
已关闭   : 21 23 25 110 143 443 445 1433 1521 2375 3000 3306 3389 5000 5173
           5432 6379 8000 8001 8080 8081 8888 9000 9090 9200 11211 27017
```

**曾修掉的一个大洞**：安全组放行了 `8080`，而容器最初映射 `0.0.0.0:8080` → 可**绕过网关直连应用**。
现容器绑定 `127.0.0.1:8080`（见 §7），公网不可达。

### 3.4 限流（宿主 nginx）

```nginx
limit_req_zone  $binary_remote_addr zone=tutor_api:10m  rate=8r/s;
limit_conn_zone $binary_remote_addr zone=tutor_conn:10m;
# 业务 location 内：
limit_req  zone=tutor_api burst=30 nodelay;
limit_conn tutor_conn 20;
```

## 四、日常操作

### 4.1 状态与日志

```bash
cd /opt/ai-tutor

docker compose ps                                  # 容器状态（期望 Up ... healthy）
docker compose logs -f --tail 100 ai-tutor         # 应用日志
tail -f backend/logs/tutor.log                     # 后端结构化日志（落 backend/logs）
journalctl -u nginx -n 50                          # 边缘网关日志
fail2ban-client status sshd                        # 封禁情况
curl -s http://127.0.0.1:8080/api/health           # 后端直连自检（绕过网关）
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1/gate   # 门口自检（期望 401）
```

### 4.2 发布（代码推到 GitHub 之后）

```bash
cd /opt/ai-tutor
git pull
docker compose up -d --build --no-deps
docker compose ps        # 等 healthy
```

> 首次构建慢在 apt 走 `deb.debian.org`（实测 ~97 KB/s）。**该层已进镜像缓存**，
> 只要 `Dockerfile` 不改就不会重跑，日常发布只重建应用层。

### 4.3 回滚

```bash
cd /opt/ai-tutor
git log --oneline -5
git checkout <上一个 commit>
docker compose up -d --build
```

### 4.4 备份 / 恢复

```bash
cd /opt/ai-tutor
docker compose stop
tar czf /root/ai-tutor-backup-$(date +%F).tar.gz data backend/data
docker compose start
# 恢复：停容器 → 解包覆盖 data/ 与 backend/data → 起容器
```

> 备份范围与 `deploy/README.md` 一致：`data/`（图谱 / 对话 / 画像）+ `backend/data`（KB 索引等）。
> **当前没有定时备份**（见 §6）。

### 4.5 换网关口令

```bash
htpasswd -bc /etc/nginx/.htpasswd tutor <新口令>
systemctl reload nginx
```

> ⚠️ **通行 Cookie 值出现在两处，改必须同步**：
> ① `/etc/nginx/sites-available/default` 的 `map $cookie_tutor_gate`
> ② `/var/www/tutor-gate/index.html` 里的 `document.cookie` 赋值
> 不同步的后果：Cookie 写入值与校验值不一致 → 无限循环跳 `/gate`。

### 4.6 自己被 fail2ban 封了

```bash
fail2ban-client set sshd unbanip <你的IP>
```

## 五、故障排查

| 症状 | 排查 |
|---|---|
| 浏览器无限跳 `/gate` | Cookie 两处不同步（见 §4.5）；或浏览器禁用了 JS/Cookie |
| 首页能开、接口全 401 | 网关误用了全站 `auth_basic`（见 §2.1），确认用的是 Cookie 方案 |
| 访问站点 502 | 容器没起：`docker compose ps` → `docker compose logs --tail 50 ai-tutor` |
| `PORT` 未配置 / 启动即退 | 根目录 `.env` 缺失或 `DASHSCOPE_API_KEY` / `SECRET_KEY` 为空（compose 用 `:?` 硬校验） |
| 对话无输出 / 一直转圈 | 看 `backend/logs/tutor.log`；确认 LLM Key 未欠费；SSE 经两层 nginx，「关缓冲」都必须在（两处 `proxy_buffering off`） |
| 上传大文件失败 | 上限 100 MB（两层 nginx 的 `client_max_body_size` 都要够） |
| 容器 healthy 但功能异常 | `/api/health` **不依赖** LLM Key，健康≠可用；以真实发一条消息为准 |

## 六、已知缺口与待办

| # | 缺口 | 影响 | 处置 |
|---|---|---|---|
| 1 | **无 HTTPS** | Basic 口令与通行 Cookie 在明文 HTTP 上可被同网嗅探；挡得住扫描器，挡不住抓包 | 需**域名**后跑 certbot（`deploy/README.md` §三）；无域名则只能自签 |

| 3 | **安全组 8080 规则未删** | 当前无进程监听 8080，不构成实际暴露，但属冗余 | 控制台删除该入方向规则 |
| 4 | **22 对全网开放** | 已仅密钥 + fail2ban，仍会被持续扫描 | 安全组授权对象收敛为固定 IP/32 |
| 5 | **无定时备份 / 无告警** | 数据仅靠手工备份 | 按需加 cron；开云安全中心免费版 |
| 6 | **未做自动安全更新** | 已知漏洞靠人工 `apt upgrade` | 可装 `unattended-upgrades` |

## 八、本次上线的决策留痕

| 决策 | 取舍 |
|---|---|
| 用 `git clone` 部署而非打包上传 | 仓库公开；后续 `git pull` 即更新 |
| 用 paramiko 而非 `sshpass`/`plink` 做自动化 | Windows 端 OpenSSH 不支持命令行传密码；pip 装到仓库外临时目录，**不污染项目 venv** |
| 容器绑 `127.0.0.1:8080` 而非依赖安全组 | 安全组实测把 8080 也放行了；**绑定是代码级保证，比人工规则可靠** |
| 网关用 Cookie 而非全站 Basic Auth | 见 §2.1 —— 全站 Basic 会与 Bearer 头冲突 |
| 口令/Cookie 都换成随机值 | 不使用 `admin123` 类默认值；`SECRET_KEY` 服务器独立生成 |
| 未换 Dockerfile 的 apt 源 | 保持服务器与仓库一致，代价是首次构建慢（该层已缓存，一次性成本） |

## 九、凭据管理

**本文不含任何凭据。** 相关凭据（SSH 私钥路径、网关口令、通行 Cookie 值）统一记在
**项目根目录 `ssh.config`**，该文件与 `id_ed25519*` 均已在 `.gitignore` 中（用 `git check-ignore -v ssh.config id_ed25519 id_ed25519.pub` 可复核）。

要点：

- SSH 私钥 `id_ed25519` 为**空口令**（为免交互运维），因此该文件等同服务器 root 权限，**只放本地、绝不入库、绝不外传**；
- 网关 Basic 口令是"进门口令"，通行 Cookie 是"进门后的手环"，两者都在 `ssh.config` 里；
- 容器 `.env` 内的 LLM / 嵌入 Key 为真实付费凭据，仅存在于服务器 `/opt/ai-tutor/.env`。
