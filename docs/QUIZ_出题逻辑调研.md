# AI 出题逻辑调研 — 依据、可靠性、变式生成

> 创建：2026-08-29
> 背景：用户提出关键问题——AI 出题不能凭空、不能乱出。最可靠方式是像作业帮一样基于**已有题库/教材**改造（改数字、改逻辑），而不是让 AI 自由发挥。本文调研论文、开源项目与博客，确定出题逻辑与可靠性方案。

---

## 一、核心结论（一句话）

**出题的"依据"= 检索增强（RAG）锚定真实教材/题库内容；出题的"可靠性"= 结构化 Schema 约束 + 多维度质量过滤器管道 + （进阶）基于已有题目做变式/参数化改造。三者叠加，防止 AI 凭空出题和乱出题。**

## 三、出题逻辑核心设计（确定方案）

### 3.1 出题"依据"三层来源（优先级从高到低）

用户说得很对——AI 不能凭空出题。我们有三层依据可选，**建议优先用已有的知识库**：

| 层级 | 依据来源 | 可靠性 | 我们是否已有 |
|------|---------|--------|-------------|
| **L1：图谱节点内容** | 从知识图谱节点（node.md）取知识点原文 | 高（AI 教学内容，可溯源） | ✅ 已有，最方便 |
| **L2：上传教材知识库** | 从 KB 上传的教材/PDF/Word 检索相关片段 | 高（真实教材，可溯源） | ✅ 已有（kb + hybrid_search） |
| **L3：对话上下文** | 从当前对话中刚学的内容出题 | 中高 | ✅ 已有 |

**推荐：L2（教材知识库）+ L1（图谱节点）双依据。** 出题时先从所选教材范围做**混合检索**（向量+BM25，复用现有 `hybrid_search` 模块）取出相关知识点片段，作为"出题依据"注入 prompt，让 AI 只能基于这些片段出题。

### 3.2 出题"可靠性"三重保障（防乱出题）

> 参考《AI智能题库系统实战》的成熟方案，结合我们项目适配：

**① 检索约束（grounding）** — 出题依据必须是检索到的真实教材片段，prompt 明确要求"**只基于以下参考材料出题，禁止生成材料中未提及的内容**"。

**② 结构化 Schema 约束** — 用 Pydantic 定义 `QuestionSchema` 强制输出格式：
```
{
  type: single | multiple | judge | fill | short_answer,  // 5种题型枚举
  difficulty: 0~1,                                        // 难度系数
  cognitive_level: 布鲁姆 记忆/理解/应用/分析/评价/创造,
  question: 题干,
  options: 选项,
  answer: 答案,
  analysis: 详细解析,
  knowledge_point: 关联知识点（用于回填图谱/标注）,
  source: 依据的教材片段引用（溯源）
}
```

**③ 质量过滤管道（QuestionFilterPipeline）** — 生成后逐题过滤，去掉不合格题目：
| 过滤器 | 作用 |
|--------|------|
| **长度过滤器** | 题干 20~500 字符（过短不完整/过长冗余） |
| **自包含性过滤器** | 正则排除"如上图所示""根据上文"等**依赖外部信息的题目** |
| **正确性过滤器** | LLM 自我验证答案正确性（关键！防止 AI 自己出题自己错） |
| **重复检测器** | 语义相似度（embedding 余弦）>0.85 判定重复，去重 |
| **难度一致性过滤器** | 校验生成难度与请求难度匹配 |

### 3.3 基于题库改造出题（用户的核心想法，进阶方案）

用户提到"作业帮有大量题库，AI 最好改数字改逻辑出题"。这对应学术界 **变式生成（Variant Generation）/ 模板化（Template-based）** 路线：

**方法 A：参数化模板出题（最可靠，推荐）**
- 教师/AI 先为典型知识点建立一个**母题模板**（带占位符）：`一个水池有 {a} 根进水管、{b} 根出水管...`
- AI 出题时**只替换参数**（数字/变量），题目结构、答案逻辑完全不变 → **100% 正确**
- 适用：数学、物理、化学等**可计算/可参数化**的题型
- 优点：**绝不可能出错**，答案可程序化验证

**方法 B：母题变式（改逻辑/改场景）**
- 已有题库/已生成的正确题目作为**母题**
- AI 基于母题改数字+局部改逻辑，生成新题
- 需要**人工审核**（human-in-the-loop）或 LLM 二次验证
- 适用：概念理解题、应用题

**方法 C：纯 RAG 生成（兜底）**
- 完全基于检索到的教材片段生成，靠 3.2 的质量管道把关
- 适用：无题库储备的开放学科

**结论：采用"方法 A 参数化优先 + 方法 C RAG 兜底"双轨。** 方法 A 保证高确定性学科不出错，方法 C 覆盖无模板学科。方法 B（人工审核）作为可选扩展。

## 四、难度评估与可靠性（进阶）

《AI智能题库系统实战》还提供了**难度评估**方法，可用于"提高出题水平"：
- **IRT 2PL 模型**：`P(θ) = 1/(1+exp(-a(θ-b)))`，用 MMLE+EM 估计难度 b 和区分度 a
- **LLM 模拟评估**：让 LLM 模拟低/中/高能力学生答题，按加权正确率算难度
  - `difficulty = 1 - (0.5×低能力正确率 + 0.3×中能力正确率 + 0.2×高能力正确率)`
  - `区分度 = 高能力正确率 - 低能力正确率`

> 建议：**MVP 阶段先做 LLM 模拟难度自评**（成本低、无统计依赖），IRT 作为后续增强。

## 附：调研原始素材要点

- RAG 出题本质：**"先检索后生成"，把真实教材片段作为生成依据，题目可溯源**，避免幻觉。
- 作业帮等题库改造：对应学术界"变式生成"（Variant Gen）/ "模板化生成"（Template-based QG），核心是**结构复用 + 内容替换**，保证答案逻辑正确。
- 干扰项质量：好干扰项应反映**学生常见认知误区**（EMNLP 2024 Distractor Survey），而非随机填充。
- 防乱出题三大件：**RAG 约束 + Schema 约束 + 过滤器管道**（CSDN 实战，最完整落地方法论）。
