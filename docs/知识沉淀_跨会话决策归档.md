⚠️ **引用任何 A/B 数字前先读 `docs/知识图谱/知识图谱_P1扩跳与AB对照实验.md` §8**。原口径只按**中文名**匹配期望知识点，而注入图谱后模型倾向抄 `node_id` 指代节点（如「从 `ab_function_call` 出发」）→ 正确回答被判 0；关闭组看不到图谱只能猜名字，猜中反而计分 → **指标同时惩罚正确行为、奖励猜测**。修正为三条口径：**定位率**（中文名 ∪ node_id，带词边界）、**引用真实 node_id**（机制证据，关闭组按构造为 0）、**状态误述**（误报图谱空 ∪ 掌握度误述，用 `nodes.mastery` 真值对照）。脚本支持 `--report-only` / `--rescore`（离线重算口径，不必重跑 LLM）与**断点续跑**（14 例 × 2 组一次跑不完，分 `--groups off/on` 两次）。

三套离线评测集（已入库）：RAG 检索 `scripts/eval_rag.py`（CMRC2018 trial 1000 条，`--embed mock` 零网络约 45s；基线 fuse R@1 0.818 / hybrid 0.766 / bm25 0.964 / vector 0.470，09-23 合并后复测逐位一致）、图谱注入 `scripts/eval_graph_injection.py`、前置推断 `scripts/eval_prerequisite.py`（F1 0.714→0.941）。**采集 / 存档 / 许可判定类改动没有评测集**（只有单元测试 + 一次性真网核对脚本）。真实 API 测试已授权（`pytest -m llm_api`、`backend/scripts/smoke_*.py`，须 `$env:PYTHONPATH="."` 在 backend 下跑）；离线 mock 通过 ≠ 真机通过。
