## 5. 环境坑（先读，能省半小时）

1. **`--basetemp` 必须是全新目录名**（带时间戳）。复用旧的会触发 safe-delete 守卫、吞掉汇总行。
2. 报 `PermissionError: …pytest-of-<user>` = 宿主沙箱对 `mkdir(mode=0o700)` 的缺陷 → 走 `.dsh_local/run_pytest.py`（把 mode 强成 0o777）。
3. **两个 app 包名冲突**：`backend/tests` 与 `backend-admin/tests` **永远分两次跑**。
4. **前端一律不碰**：受限沙箱里 `npx vitest run` 报 `spawn EPERM`（Node 子进程管道被禁）→ 改了没法验 = 埋雷。前端问题写进交底报告，留到 10/15 后。
5. 不跑 `-m llm_api`（真付费 key、慢、flaky）；不起常驻 uvicorn/vite；不跑 `npm install`/`vite build`/`docker build`。
