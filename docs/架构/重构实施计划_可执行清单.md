### 1.4 ⚠️ 本机跑测试的两个坑（照抄）

**坑① 沙箱：`mkdir(mode=0o700)` 会造出不可读、不可删的目录**（最小复现 3 行，见审计文档 §5）。
pytest 的 `tmpdir` 插件正好用 `basetemp.mkdir(mode=0o700)`（`_pytest/tmpdir.py:158`）→ 用 `tmp_path` 的用例全挂。
**兜底脚本**（`.dsh_local/run_pytest.py`，**临时文件，勿提交**；进 pytest 前把 `Path.mkdir` 的 mode 强制成 `0o777`）：

```powershell
# 后端（cwd = 仓库根）
backend/venv/Scripts/python.exe .dsh_local/run_pytest.py backend/tests -q -m "not llm_api" `
    -p no:cacheprovider --basetemp=.dsh_local/pytest_tmp

# 运维后台（cwd = 仓库根；**必须单独一次调用**）
backend/venv/Scripts/python.exe .dsh_local/run_pytest.py backend-admin/tests -q `
    -p no:cacheprovider --basetemp=.dsh_local/pytest_tmp_admin
```

脚本本体（**新克隆的仓库没有这个文件，按下面内容自建**；会话切「完全权限」后可删）：

```python
# .dsh_local/run_pytest.py —— 临时兜底：进 pytest 前把 Path.mkdir 的 mode 强制成 0o777
import pathlib, sys
_orig = pathlib.Path.mkdir
pathlib.Path.mkdir = lambda self, mode=0o777, parents=False, exist_ok=False: \
    _orig(self, 0o777, parents, exist_ok)
import pytest
sys.exit(pytest.main(sys.argv[1:]))
```

**坑② 两个套件不能合在一次 pytest 调用里**：两边包名都叫 `app`，先被收集的一方会把
`backend/` 塞进 `sys.path`，另一方就 `ModuleNotFoundError: app.core.admin_auth`。→ **永远分两次跑**。
（`backend-admin/venv` 存在但**没装 pytest**，后台套件用 `backend/venv` 的 python 跑。）

**会话切到「完全权限」后**：上面 `run_pytest.py` 不再需要，直接 `pytest` 即可；并顺手删掉
`.pytest_probe_tmp2`、`.pytest_probe_tmp3`、`.pytest_tmp_audit`、`.probe_mode700`（沙箱缺陷产物，`Remove-Item` 会失败）。
