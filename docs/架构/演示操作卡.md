## 2. 演示脚本（8 分钟版）

> 左侧活动栏的五个入口：**对话 / 学习进度 / 知识图谱 / 出题 / 资源采集**；左下齿轮 = 设置，左下头像 = 用户菜单。
> 每步都给了**兜底**：出问题时按兜底走，**不要现场调试**。

### 第 1 幕｜知识图谱（60 s）

| | |
|---|---|
| **操作** | 活动栏 →「知识图谱」→ 选一个学科 |
| **预期现象** | D3 力导向图；节点按掌握度**四色**着色 + 图例；搜索框输入关键词→视图聚焦；点节点→右侧详情（小节清单/标记/掌握度） |
| **讲解点** | "图里每个点是一个知识点，连边是先后修关系；颜色深浅 = 掌握度——**这张图是 AI 每次对话沉淀出来的**，不是手画的。" |
| **兜底** | 图空/太挤 → 用搜索框聚焦某个关键词；仍空 → 换一个已有数据的学科，别现场建图 |

### 第 2 幕｜学习进度仪表盘（30 s）

| | |
|---|---|
| **操作** | 活动栏 →「学习进度」 |
| **预期现象** | 掌握/学习中/未学统计、平均掌握度、薄弱点列表、学科进度 |
| **讲解点** | "这些数字不是写死的：出题答对 → 该小节自动记通过 → 掌握度跟着动。" |
| **兜底** | 数字全 0 → 说明账号没数据，回第 1 幕用有数据的账号 |

### 第 3 幕｜对话 = Agent Loop（90 s）

| | |
|---|---|
| **操作** | 活动栏 →「对话」→ 发一句「我想学二重积分，从零讲起」 |
| **预期现象** | **思考**气泡 → 工具调用过程（建节点/检索资料）→ 正文**逐字流出**；回答结束后图谱侧栏/图谱页多出节点 |
| **讲解点** | "对话不是一问一答：模型在后台**多轮调工具**（建图谱节点、检索资料、出题），思考与工具进度通过 SSE 实时推给你——这条链就是 Agent Loop。" |
| **兜底** | **没有逐字流** → 等 5 s；仍无 → 刷新页面（F5）重发一次。前端一直空 → 看 `logs\uvicorn-dev.log` 是否在滚动 |

### 第 4 幕｜按小节教学 + 先问再出题（180 s，**核心**）

| | |
|---|---|
| **操作** | 回「知识图谱」→ 点一个节点 →「去学习」→ 等开场（只报菜单）→ 说「先讲第一节」→ 听完说「好，出题吧」→ 作答 |
| **预期现象** | ① 开场轮**只报小节菜单**（不调工具、不一口气讲完，后端 `no_tools` 硬保证）；② 说"讲第一节"→ **只讲一节就停**，等你回应；③ 说"出题吧"→ 约 **40 秒**后题卡推到对话里；④ 作答 → 判分结论**单独成行**（答对/答错 + 得分/解析）→ 小节变「已通过」→ 掌握度进仪表盘 |
| **讲解点** | "这里有两个被真机打脸后改硬的设计：**出题前必须先问学生**（模型自己说的'稍等，题马上来'不算数，后端查工具轨迹，没调就补一道）；**判分是规则判的**，模型不许改口说'答对了'。" |
| **兜底** | 题卡 40 s 没来 → 等满 60 s，再问一句「题呢？」（会触发下一轮兜底）；仍无 → 跳过本幕，**别现场猜**；出题失败就只演讲解 + 判分历史题 |

### 第 5 幕｜知识库 + 混合检索（90 s）

| | |
|---|---|
| **操作** | 对话页右侧**知识库面板** → 上传一份**电子版** PDF/Word → 等索引完成 → 在对话里问一个只能从这份资料回答的问题 |
| **预期现象** | 目录树里出现该文件；回答**带来源引用**（文件名/路径）；点文件可预览原件 |
| **讲解点** | "检索是**向量 + BM25 混合**再融合，不是单路向量；每条回答都能溯源到具体文件。" |
| **兜底** | 上传慢（大文件分钟级）→ 换**小**文件（1–2 MB 电子版 PDF）；⚠️ **绝对不要**现场上传扫描版 PDF（OCR 逐页识别是分钟级） |

### 第 6 幕｜运行记录与证据回放（60 s，**被追问时的底牌**）

| | |
|---|---|
| **操作** | 打开 <http://localhost:5174> → `admin / admin123` → 按 `run_id` 查刚才那次对话 |
| **预期现象** | 思考全文、每个工具的参数与返回、最终回答、停止原因（`stop_reason`） |
| **讲解点** | "**凭什么说它真调了工具**——这里有一次运行的全部证据，不是我们事后补的截图。" |
| **兜底** | 进不去 → 确认 8001 端口起了；这个后台只是加分项，进不去就跳过 |

### 第 7 幕｜工程质量证据（**可录屏，90 秒**）

```powershell
cd C:\Users\34239\Documents\GitHub\AI-tutor
backend/venv/Scripts/python.exe .dsh_local/run_pytest.py backend/tests -q -m "not llm_api" -p no:cacheprovider --basetemp=.dsh_local/tmp_demo_1010
# 期望最后一行：1566 passed, 7 deselected
backend/venv/Scripts/python.exe .dsh_local/run_pytest.py backend-admin/tests -q -p no:cacheprovider --basetemp=.dsh_local/tmp_demo_admin_1010
# 期望：41 passed（⚠️ 必须单独一次调用：两边包名都叫 app，合跑必 ModuleNotFoundError）
```

| | |
|---|---|
| **讲解点** | "1,566 例离线测试，90 秒跑完；这个项目每一处硬约束（单 worker、通知先落库、上传原子回滚）都有对应用例锁着。" |
| **兜底** | ⚠️ `--basetemp` 必须是**全新目录名**（带日期/序号）；复用旧目录会触发 safe-delete 守卫、吞掉汇总行。若报 `PermissionError: …pytest-of-<user>` → 就是用了 `.dsh_local/run_pytest.py`（已兜住）；还报 → 改跑**定向**用例（`test_learn_mode.py test_learn_stream_path.py`），别取消整幕 |

## 3. 故障对照表（现象 → 处理）

| 现象 | 最可能原因 | 处理 |
|---|---|---|
| 对话**完全没反应**、没有流式输出 | SSE 断（后端重启过）/ 浏览器长连接掉了 | F5 刷新重发；仍无 → 看 `logs\uvicorn-dev.log` 有无 `[E-CHAT-…]` |
| 对话报模型错误 | Key 未配 / 额度耗尽 / 地址写错 | 设置页 →「模型」检查主档；或换备用档位；**不要**现场改 `.env` 后等重启（会掐断所有 SSE） |
| 图谱页不更新 | 事件推送断了 | 手动刷新页面（后端改动会自动触发前端重挂，但演示中**不要**改代码） |
| 上传资料后 AI 看不到内容 | 索引失败（曾出现"有正文无索引"的孤儿） | 重新上传一次；或换小文件 |
| 题卡一直不来 | 后台出题在跑（~40 s）/ 已有未作答的题 | 等满 60 s；先答掉手上那道题 |
| 后端起不来、端口占用 | 上一个进程没退 | `Get-NetTCPConnection -LocalPort 8000` 找到 PID 后停掉，或换端口（前端代理要同步改 → **不推荐现场换**） |
| 前端白屏 | 依赖没装全 | ⛔ 不现场 `npm install`；换用**已装好**的机器或录屏前修好 |
| 测试报 `ModuleNotFoundError: No module named 'app'` | 两个 `app` 包混跑 | 分两次跑，别把 `backend/tests` 与 `backend-admin/tests` 合在一条命令里 |

## 4. 现场红线（违反必翻车）

- ⛔ **不改代码、不提交**：演示期间后端 `--reload` 一重启，所有 SSE 长连接断开，前端会"抽一下"。
- ⛔ **不 `npm install` / `npm run build` / `docker build`**：分钟级，且会把镜头时间吃光。
- ⛔ **不跑 `-m llm_api`**（真实付费 Key、慢、flaky）。
- ⛔ **不上传扫描版 PDF**（OCR 分钟级）、**不现场生成整本教材图谱**（分钟级批量 LLM）。
- ⛔ **不演"模型自动降级"**（要打爆额度才看得到，不可控）。
- ✅ 出问题就**切到下一幕**：8 分钟脚本里每一幕都能独立成立，第 6/7 幕（证据 + 测试）是兜底的王牌。
