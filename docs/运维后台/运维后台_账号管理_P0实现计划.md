## 1. 现状分析

### 1.1 现有用户表结构

```sql
-- 位置: data/knowledge/knowledge.db
CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    username TEXT UNIQUE NOT NULL,
    password_hash TEXT NOT NULL,
    created_at TEXT DEFAULT (datetime('now'))
)
```

### 1.2 现有代码

| 文件 | 功能 |
|------|------|
| `app/api/v1/auth.py` | 注册、登录、获取当前用户 |
| `app/core/auth.py` | 密码哈希、JWT 生成、Token 解析 |
| `app/main.py` | 启动时创建默认 admin 账户 |

### 1.3 需要扩展

- 缺少 `role` 字段（角色）
- 缺少 `status` 字段（启用/禁用）
- 缺少 `last_login_at` 字段（最后登录时间）

## 2. 实现方案

### 2.1 数据库迁移

```sql
-- 新增字段（已有数据自动获默认值）
ALTER TABLE users ADD COLUMN role TEXT DEFAULT 'user';
ALTER TABLE users ADD COLUMN status TEXT DEFAULT 'active';
ALTER TABLE users ADD COLUMN last_login_at TEXT;
```

### 2.2 API 设计

| 端点 | 方法 | 鉴权 | 功能 |
|------|------|------|------|
| `/api/v1/admin/users` | GET | Admin | 用户列表（分页+搜索+筛选） |
| `/api/v1/admin/users/{id}` | GET | Admin | 用户详情 |
| `/api/v1/admin/users/{id}/disable` | POST | Admin | 禁用用户 |
| `/api/v1/admin/users/{id}/enable` | POST | Admin | 启用用户 |

### 2.3 请求/响应模型

**GET /users 查询参数**：
- `page`: 页码（默认 1）
- `page_size`: 每页数量（默认 20）
- `search`: 用户名搜索（模糊匹配）
- `status`: 状态筛选（active/disabled）

**GET /users 响应**：
```json
{
  "total": 100,
  "page": 1,
  "page_size": 20,
  "users": [
    {
      "id": 1,
      "username": "admin",
      "role": "admin",
      "status": "active",
      "created_at": "2026-01-01 12:00:00",
      "last_login_at": "2026-09-19 10:30:00"
    }
  ]
}
```

**GET /users/{id} 响应**：
```json
{
  "id": 1,
  "username": "admin",
  "role": "admin",
  "status": "active",
  "created_at": "2026-01-01 12:00:00",
  "last_login_at": "2026-09-19 10:30:00"
}
```

### 2.4 角色定义

| 角色 | 说明 | 权限 |
|------|------|------|
| `super_admin` | 超级管理员 | 所有操作（包括管理其他管理员） |
| `admin` | 管理员 | 用户管理，但不能禁用 super_admin |
| `user` | 普通用户 | 无管理权限 |
