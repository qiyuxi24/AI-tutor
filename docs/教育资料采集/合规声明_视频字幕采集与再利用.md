## 一、三层许可框架（为什么"解析视频"要分情况看）

视频/字幕的采集与再利用是否"被允许"，取决于三个**互相独立**的许可层：

| 层面 | 依据 | 结论 |
|---|---|---|
| **① 著作权法** | 《著作权法》第24条：**为个人学习、研究或者欣赏**，使用他人已发表的作品，可不经许可、不付报酬 | **个人自用=合理使用，不侵权** |
| **② 平台协议** | B 站用户协议 **4.3.15**：未经书面许可，不得以机器人/爬虫/脚本等自动程序获取平台内容、数据 | **自动抓取=违约**（后果：限流/封号/封 IP，非刑事） |
| **③ 技术措施** | 《著作权法》第49条：不得故意避开/破坏技术措施；第53条：未经许可复制/发行/**通过信息网络向公众传播**=侵权 | **破解 DRM 或下载付费内容=侵权** |

**一句话**：个人下载、个人自用受合理使用保护；向公众传播、商用、破解技术措施才是真正的高危红线。

## 五、法律依据摘要

| 依据 | 要点 |
|---|---|
| 《著作权法》第24条 | 为个人学习、研究、欣赏使用已发表作品，可不经许可、不付报酬（合理使用） |
| 《著作权法》第49、50条 | 不得故意避开/破坏技术措施；例外：教学科研、反向工程研究等 |
| 《著作权法》第53条 | 未经许可复制/发行/通过信息网络向公众传播=侵权（民事责任；损害公共利益另有行政/刑事责任） |
| 《信息网络传播权保护条例》第12条 | 教学科研等情形可避开技术措施，但不得向他人提供避开手段 |
| 法释〔2025〕5号 | 侵犯著作权罪的"向公众传播"数量门槛（下载量1万次/点击10万次/会员制等） |
| B 站用户协议 4.3.15 | 未经书面许可，不得以自动程序获取平台内容、数据 |
