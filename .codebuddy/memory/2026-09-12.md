## 完成：零依赖小修两项（用户选定）

### ① Collector 遗留债 #1 — MediaWiki 地区词标记 `-{…}-` 清理
`backend/app/core/collector/adapters/wikipedia.py` 新增 `_strip_variant()`（置于 `wikitext_to_md` 内、`_drop_templates` **之前**，这样 `-{H|…}-` 规则定义里的 `{{}}` 也被清掉）：
- `-{zh-cn:堆叠; zh-tw:堆棧;}-` → 取第一个变体值 `堆叠`（`split(";")[0]` → `split(":",1)[-1]`）
- `-{H|zh-cn:栈;zh-tw:棧;}-` → 整段丢（`inner[:2].upper() == "H|"`）
- `-{A|B}-` → 取前者，但 `if "[[" not in inner` 保护，不切坏 `[[链接|文字]]`
- `-{}-` / 无冒号裸文本 → 原样/空
- 嵌套用 `while "-{" in text` + `re.subn`（n==0 即 break，不会死循环）

### ② 向量检索维度校验
`backend/app/core/rag/vector_store.py` + `backend/app/core/kb/doc_vector_store.py`：`search()` 循环内加 `if vec.shape != q.shape: skipped += 1; continue`（放在 norm 之前），循环后若 skipped 则 `logger.warning`（两模块首次引入 `logging.getLogger(__name__)`）。原先 `np.dot` 维度不符直接 ValueError → 500。返回 `[]` 而非报错，混合检索仍有 BM25 兜底。做法与 `kb/embedder.py::BaseEmbedder.similarity` 的既有维度保护一致（复用既有约定）。
