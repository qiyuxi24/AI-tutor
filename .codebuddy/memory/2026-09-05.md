## Ponytail skill 安装（必调用）

用户要求拉取 Ponytail 仓库装到项目里，并作为以后「必调用」的 skill。

**Ponytail 是什么**：`DietrichGebert/ponytail`（MIT，127k stars），一套让 AI 编码 Agent 遵循「最小必要实现/YAGNI」的 skill 集合。核心是七阶决策阶梯（1 这功能需要吗→2 代码库已有吗→3 标准库→4 原生特性→5 已装依赖→6 一行→7 才写最少代码）+ 6 个 skill（ponytail / -review / -audit / -debt / -gain / -help）。

**落地**：
- GitHub `git clone` 直连两次失败（connection reset / 443 超时），改用 `curl -L https://codeload.github.com/DietrichGebert/ponytail/zip/refs/heads/main` 下载 1.09M zip 成功，解压重命名为 `.codebuddy/skills/ponytail/`。
- 在 `.codebuddy/skills/ponytail/SKILL.md` 创建 CodeBuddy 主 skill 入口（CodeBuddy 识别路径是 `.codebuddy/skills/<name>/SKILL.md`），description 强化「MANDATORY/必调用」，正文复用官方 skills/ponytail/SKILL.md 的七阶阶梯全文。
- 仓库原 skills/ 子目录（6 个 skill）保留在 `.codebuddy/skills/ponytail/skills/` 下，未单独暴露（用户只要求主 ponytail skill）。
- 清理了临时 zip。

**CodeBuddy skill 机制结论**（查官方文档）：项目级 `.codebuddy/skills/<name>/SKILL.md`、用户级 `~/.codebuddy/skills/<name>/SKILL.md`；自动调用靠 SKILL.md 的 description 触发词，无 `always:true` 字段，需靠 description 强化「必调用」+ 重启会话生效。

- ponytail-audit：全库过度设计审计（ranked 删减清单，一次性不改码）
- ponytail-debt：收集 `ponytail:` 注释成债务台账（grep 标记，只读）
- ponytail-help：级别(lite/full/ultra)+skills 速查卡（已加注 CodeBuddy 无斜杠命令、靠 description 触发）
